## 🚀 Quick Start Guide

### Step 1: Download
```bash
# Download latest release (800MB ISO)
wget https://github.com/ai-rescue-usb/ai-rescue-usb/releases/latest/download/ai-rescue-usb.iso

# Verify integrity
sha256sum ai-rescue-usb.iso
# Should match: <checksum from website>
```

### Step 2: Create USB Drive

**Linux:**
```bash
# Find your USB drive
lsblk

# Flash (replace /dev/sdX with your drive)
sudo dd if=ai-rescue-usb.iso of=/dev/sdX bs=4M status=progress
sync
```

**Windows:**
```powershell
# Option A: Run flasher (easiest)
.\flash-usb-windows.bat

# Option B: Use Rufus
# 1. Download Rufus from rufus.akeo.ie
# 2. Select ai-rescue-usb.iso
# 3. Click START
```

**macOS:**
```bash
# Find your USB drive
diskutil list

# Flash (replace /dev/diskN with your drive)
sudo dd if=ai-rescue-usb.iso of=/dev/rdiskN bs=4m
```

### Step 3: Boot from USB
```
1. Insert USB into the computer you need to fix
2. Restart computer
3. Press boot menu key during startup:
   - Dell: F12
   - HP: F9
   - Lenovo: F12 or Nova button
   - Asus: F8 or Esc
   - Acer: F12
   - Toshiba: F12
   - Apple: Option (Alt)
4. Select "USB" or "Removable Device"
5. Wait for AI Rescue USB to load (~30 seconds)
```

### Step 4: Talk to AI
```
AI: "Welcome to AI Rescue USB!
     I can help you repair, install, or recover data.
     What do you need help with?"

You: "My computer is really slow"

AI: "I'll diagnose the issue. Give me 10 seconds..."
    [Scanning system...]
AI: "Found the problems:
     1. Only 1.2GB RAM free (need 4GB+)
     2. Hard drive at 95% capacity
     3. 23 startup programs
     
     Recommendations:
     - Remove 15 startup programs (safe)
     - Clean 12GB of temp files
     - Upgrade RAM to 8GB
     
     Should I apply the software fixes first?"
```

## 🏗️ Development

### Prerequisites
- Python 3.11+
- Node.js 18+ (for UI)
- Docker (for building ISO)
- QEMU (for testing)

### Setup
```bash
# Clone repository
git clone https://github.com/ai-rescue-usb/ai-rescue-usb.git
cd ai-rescue-usb

# Install Python dependencies
pip install -r requirements.txt

# Install Node dependencies
cd ui && npm install && cd ..

# Run in development mode
python ui/server.py
# Open http://localhost:8080
```

### Build ISO
```bash
# Full build (requires Docker)
./build-all.sh

# Or build without Docker
./scripts/build-base.sh
cd build && ./create-iso.sh
```

### Test with QEMU
```bash
# Test ISO
qemu-system-x86_64 -enable-kvm -m 4G -cdrom build/ai-rescue-usb.iso

# Test USB image
qemu-system-x86_64 -enable-kvm -m 4G -drive file=build/ai-rescue-usb.img,format=raw
```
